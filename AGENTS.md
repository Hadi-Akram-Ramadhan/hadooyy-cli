# Portable agent setup

When asked to set up this repository, read SETUP.md completely before doing anything.
Ask the recipient for target agent/profile, their nickname, assistant nickname, persona,
and whether to preserve existing authentication or configure their own provider/model.
Never request API keys, passwords, cookies or OAuth codes in chat. Use official local login.
Run setup.py in read-only mode first. Explain changes, obtain consent, then apply.
Install and verify MCP/plugins using SETUP.md; copying files alone is not completion.
Never inherit the repository author's identity, credentials, machine paths or bypass permissions.
Never commit, push or merge without explicit permission.
